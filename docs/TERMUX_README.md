## 🤔 Что такое Termux?

**Termux** - это эмулятор терминала для Android, который предоставляет среду Linux без необходимости root.

### Возможности Termux
- ✅ Полноценный терминал Linux
- ✅ Управление пакетами (pkg)
- ✅ Поддержка Python, Node.js, Ruby и др.
- ✅ Доступ к файловой системе Android
- ✅ Работа с сетью
- ✅ Кастомизация через dotfiles
- ✅ Поддержка горячих клавиш

### Ограничения Termux
- ❌ Нет доступа к системным файлам (без root)
- ❌ Ограниченный доступ к некоторым API Android
- ❌ Некоторые пакеты недоступны
- ❌ Ограничения по памяти и процессору

## 📥 Установка Termux

### Официальная установка

**Важно:** Устанавливайте только из F-Droid!

```bash
# Скачайте из F-Droid
# https://f-droid.org/packages/com.termux/
```

### Почему не Google Play?

- Версия в Google Play устарела
- Нет обновлений с 2019 года
- Многие функции не работают
- Проблемы с безопасностью

### Первичная настройка

```bash
# Обновите пакеты
pkg update && pkg upgrade

# Разрешите доступ к хранилищу
termux-setup-storage

# Настройте дополнительные кнопки (опционально)
termux-setup-storage
```

## 💻 Основные команды

### Управление пакетами

```bash
# Обновление пакетов
pkg update

# Обновление системы
pkg upgrade

# Поиск пакета
pkg search <имя>

# Установка пакета
pkg install <имя>

# Удаление пакета
pkg uninstall <имя>

# Информация о пакете
pkg info <имя>

# Очистка кэша
pkg clean

# Удаление неиспользуемых пакетов
pkg autoremove
```

### Работа с файлами

```bash
# Навигация
cd <папка>           # Переход в папку
cd ..                # На уровень выше
cd ~                 # В домашнюю папку
cd /                 # В корень

# Просмотр содержимого
ls                   # Список файлов
ls -la               # Подробный список
ls -lh               # С размерами

# Создание
mkdir <папка>        # Создать папку
touch <файл>         # Создать файл

# Копирование
cp <источник> <цель> # Копировать файл/папку
cp -r <папка> <цель> # Копировать папку рекурсивно

# Перемещение/переименование
mv <источник> <цель> # Переместить/переименовать

# Удаление
rm <файл>            # Удалить файл
rm -r <папка>        # Удалить папку
rm -rf <папка>       # Удалить принудительно

# Просмотр содержимого
cat <файл>           # Вывод содержимого
less <файл>          # Просмотр с прокруткой
head <файл>           # Первые строки
tail <файл>           # Последние строки

# Редактирование
nano <файл>          # Редактор nano
vim <файл>           # Редактор vim
```

### Работа с процессами

```bash
# Просмотр процессов
ps                   # Список процессов
ps aux               # Подробный список
top                  # Мониторинг процессов

# Управление процессами
kill <PID>           # Убить процесс по ID
pkill <имя>          # Убить процесс по имени
killall <имя>        # Убить все процессы

# Фоновый режим
<команда> &          # Запустить в фоне
nohup <команда> &    # Запустить в фоне без прерывания
jobs                 # Список фоновых задач
fg <номер>           # Перенести на передний план
bg <номер>           # Перенести на фон

# Мониторинг
htop                 # Мониторинг системы
```

## 📁 Работа с файлами

### Доступ к хранилищу Android

```bash
# После termux-setup-storage
cd /sdcard           # Внутренняя память
cd /sdcard/Download  # Загрузки
cd /sdcard/Pictures  # Изображения
cd /sdcard/Documents # Документы
```

### Работа с архивами

```bash
# ZIP
unzip <файл>.zip     # Распаковать
zip -r <архив>.zip <папка>  # Запаковать

# TAR
tar -xvf <файл>.tar  # Распаковать
tar -cvf <архив>.tar <папка>  # Запаковать

# TAR.GZ
tar -xzvf <файл>.tar.gz  # Распаковать
tar -czvf <архив>.tar.gz <папка>  # Запаковать
```

### Поиск файлов

```bash
# Поиск по имени
find <папка> -name "<имя>"

# Поиск по содержимому
grep "<текст>" <файл>
grep -r "<текст>" <папка>

# Поиск по размеру
find <папка> -size +100M  # Больше 100 МБ
find <папка> -size -10M   # Меньше 10 МБ
```

## 🔄 Работа с процессами

### Запуск в фоне

```bash
# Простой запуск в фоне
~/start_fcc_server.sh &

# Запуск с перенаправлением вывода
nohup ~/start_fcc_server.sh > server.log 2>&1 &

# Проверка фоновых задач
jobs

# Просмотр логов
tail -f server.log
```

### Управление процессами

```bash
# Найти процесс
ps aux | grep fcc

# Убить процесс
pkill fcc-server

# Проверить статус
pgrep -f fcc-server
```

### Автозапуск

```bash
# Добавить в ~/.bashrc
echo '~/start_fcc_server.sh &' >> ~/.bashrc

# Или создать скрипт автозапуска
cat > ~/.termux/boot.sh << 'EOF'
#!/usr/bin/env bash
~/start_fcc_server.sh &
EOF
chmod +x ~/.termux/boot.sh
```

## 🔒 Безопасность

### Основные правила безопасности

1. ✅ Используйте сильные пароли
2. ✅ Не передавайте API ключи
3. ✅ Используйте SSH ключи
4. ✅ Обновляйте пакеты регулярно
5. ✅ Не используйте root без необходимости
6. ✅ Ограничивайте права доступа

### Управление правами доступа

```bash
# Изменение прав
chmod 755 <файл>     # rwxr-xr-x
chmod 644 <файл>     # rw-r--r--
chmod +x <скрипт>    # Сделать исполняемым

# Изменение владельца
chown user:group <файл>

# Изменение группы
chgrp group <файл>
```

### Безопасное хранение ключей

```bash
# Создайте безопасную папку
mkdir -p ~/.secure
chmod 700 ~/.secure

# Храните ключи там
cp api_key.txt ~/.secure/
chmod 600 ~/.secure/api_key.txt
```

### Алиасы

```bash

alias ...='cd ../..'
alias grep='grep --color=auto'

# Перезагрузите конфигурацию

```

### Функции

```bash
# Добавьте в ~/.bashrc
function mkcd() {
    mkdir -p "$1" && cd "$1"
}

function extract() {
    if [ -f $1 ]; then
        case $1 in
            *.tar.gz) tar xzf $1 ;;
            *.tar) tar xf $1 ;;
            *.zip) unzip $1 ;;
            *) echo "Неизвестный формат" ;;
        esac
    fi
}

# Перезагрузите конфигурацию
source ~/.bashrc
```

## 🆘 Решение проблем

### Проблема: Нет доступа к интернету

**Решение:**
```bash
# Проверьте соединение
ping google.com

# Проверьте VPN/Proxy
# Отключите VPN и попробуйте снова

# Перезапустите Termux
# Настройки → Termux → Очистить кэш
```

### Проблема: Ошибки при установке пакетов

**Решение:**
```bash
# Обновите пакеты
pkg update && pkg upgrade

# Очистите кэш
pkg clean

# Переустановите проблемный пакет
pkg uninstall <пакет>
pkg install <пакет>
```

### Проблема: Недостаточно места

**Решение:**
```bash
# Проверьте место
df -h

# Очистите кэш
pkg clean

# Удалите ненужные пакеты
pkg autoremove

# Очистите логи
rm -rf ~/.cache/*
```

### Проблема: Команда не найдена

**Решение:**
```bash
# Проверьте PATH
echo $PATH

# Добавьте в PATH
export PATH="$HOME/.local/bin:$PATH"

# Или добавьте в ~/.bashrc
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### Проблема: Файл не найден

**Решение:**
```bash
# Проверьте текущую папку
pwd

# Проверьте существование файла
ls -la <файл>

# Используйте полный путь
ls -la /полный/путь/к/файлу
```

### Проблема: Ошибки прав доступа

**Решение:**
```bash
# Проверьте права
ls -la <файл>

# Измените права
chmod 755 <файл>
chmod +x <скрипт>

# Измените владельца
chown $USER:$USER <файл>
```
