## 🎯 Описание пакета

**Free Claude Code - Termux Installer** - это автоматический установщик для запуска Free Claude Code на Android через Termux.

### Назначение

Пакет предназначен для:
- ✅ Упрощения установки Free Claude Code на Android
- ✅ Автоматизации настройки окружения
- ✅ Обеспечения стабильной работы на мобильных устройствах
- ✅ Предоставления готовых скриптов запуска
- ✅ Упрощения обновления и обслуживания

### Целевая аудитория

- 📱 Пользователи Android
- 💻 Разработчики на мобильных устройствах
- 🎓 Студенты и обучающиеся
- 🔧 Энтузиасты и экспериментаторы
- 🌍 Пользователи из регионов с ограниченным доступом

## ⚙️ Конфигурация

### Иерархия конфигурации

1. **Переменные окружения** (termux_env.sh)
2. **Конфигурационный файл** (config.yaml)
3. **Аргументы командной строки**
4. **Значения по умолчанию**

### Основные настройки

#### API настройки
```yaml
api:
  provider: "openrouter"
  api_key: "sk-or-v1-xxxxxxxx"
  base_url: "https://openrouter.ai/api/v1"
```

#### Модель
```yaml
model:
  name: "anthropic/claude-3.5-sonnet"
  temperature: 0.7
  max_tokens: 4096
```

#### Сервер
```yaml
server:
  host: "0.0.0.0"
  port: 8082
  debug: false
```

#### Кэш
```yaml
cache:
  enabled: true
  ttl: 3600
```

#### Rate limiting
```yaml
rate_limit:
  enabled: true
  requests_per_minute: 60
```

### Профили конфигурации

**Development:**
- Отладка включена
- Кэш отключен
- Rate limiting отключен
- Подробное логирование

**Production:**
- Отладка отключена
- Кэш включен
- Rate limiting включен
- Минимальное логирование

**Minimal:**
- Только необходимые настройки
- Минимальный размер
- Быстрая установка

## 🔗 Интеграция

### Интеграция с Termux

**Переменные окружения:**
```bash
export PATH="$HOME/.local/bin:$PATH"
export FCC_HOME="$HOME/.config/fcc"
```

**Интеграция с bashrc:**
```bash
# Автозагрузка окружения
source ~/free-claude-code-termux/config/termux_env.sh
```

### Интеграция с Android

**Доступ к хранилищу:**
```bash
termux-setup-storage
cd /sdcard/Download
```

**Уведомления:**
```bash
termux-notification --title "FCC" --content "Сервер запущен"
```

**Интеграция с другими приложениями:**
- Совместимость с Termux:API
- Поддержка Termux:Widget
- Интеграция с Tasker

### Интеграция с API провайдерами

**OpenRouter:**
```yaml
api:
  provider: "openrouter"
  base_url: "https://openrouter.ai/api/v1"
```

**DeepSeek:**
```yaml
api:
  provider: "deepseek"
  base_url: "https://api.deepseek.com/v1"
```

**NVIDIA NIM:**
```yaml
api:
  provider: "nvidia"
  base_url: "https://integrate.api.nvidia.com/v1"
```
